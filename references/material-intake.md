# 材料整理与脱敏

先说明分析目的与期限，再建立仅含元数据的来源台账：`id`、`type`、`label`、`as_of`。原始薪酬导出、聊天和文件路径留在用户授权环境，不写入公开报告、测试夹具或视觉资产。

## 最小字段

| 对象 | 可保留字段 | 不能进入生成器 |
|---|---|---|
| 薪酬带宽 | 匿名带宽 ID、岗位族群、职级、地点、下限/中点/上限 | 内部文件路径、审批信息 |
| 人员记录 | 匿名 `person_ref`、带宽 ID、基础薪资、已解释中性因素 | 姓名、联系方式、受保护属性、家庭、健康、薪酬历史 |
| 市场数据 | 来源标签、截至日期、岗位/级别/地点、货币、周期、P25/P50/P75 | 未获授权的第三方原始数据 |

## 归一化顺序

1. 统一币种与周期；无法统一则分开呈现。
2. 用岗位族群、职级、地点映射带宽；没有映射时不计算区间位置。
3. 用稳定匿名标识替代姓名；标识应只在当前授权环境可回溯。
4. 把已知解释限制在职责范围、任职时间、稀缺技能、地点政策或已批准例外等可复核业务字段。
5. 标出截至日期与来源。市场数据过期、口径不一致或来源不明时只列为待核。
